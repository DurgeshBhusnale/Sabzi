Localization stress test · Hindi and Marathi

The tightest components rendered with real Hindi and Marathi strings, which run about 30–35% longer than English. Every component holds at a 360px phone width without clipping or overlap.

Rules applied

  • Font stack: Noto Sans Devanagari with Inter for Latin and digits.
  • Line-height 1.5 on all Devanagari text; matras clip at 1.2.
  • No fixed heights on text containers, only min-height.
  • No uppercase or letter-spacing on Hindi or Marathi.
  • No line clamping on notifications, errors or help text.
  • Pills, tabs and nav labels share width by content and wrap.
  • Numerals follow user locale: Marathi uses ०–९; prices keep the ₹ sign.
